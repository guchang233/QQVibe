# QQVibe 1.2.2 发布记录

本版优化聊天消息的情绪与意图识别，支持 API 批量分析和流式标签显示，并修复 Windows MIME 映射异常及启动失败后的后台进程残留问题。功能说明见 [更新日志](../../CHANGELOG.md)，开发结构见 [后端架构说明](../backend-architecture.md)。

## 交付内容

- **Windows 应用包**：`QQVibe-1.2.2-windows-x64.zip`，不内置模型。
- **源码包**：`QQVibe-1.2.2-source.zip`，包含本版源码、测试及公开文档；对应仓库 `v1.2.2` 标签。
- **更新文件**：`update-manifest.json`、`update-manifest.sig`、`SHA256SUMS.txt`。
- **独立模型**：继续使用 `QQVibe-Laya-model-v1.zip`，客户端固定从 v1.2.0 的 Release 资产下载；模型文件与版本未变更。

Windows 应用包大小为 **349,836,708 字节**，SHA-256：

```text
2f172025efda3176194f10d95fdf98cc0a97ba178a0c54893702132ae7b79d36
```

本次正式同步源码和文档，沿用已验收的应用 ZIP、更新清单及签名。已安装 1.2.2 的用户无需重复安装。

## 源码与运行包对应关系

正式源码与发布包完成 119 项运行文件比对，包括 Electron ASAR 中的启动、下载和更新脚本，未发现运行代码差异。源码侧另行修正了一个跨 VM 对象比较的测试断言，并更新 README、更新日志与架构说明；这些调整不改变已发布应用的行为。包内附带的旧版 README 保留原样，最新说明以仓库文档为准。

源码包只包含审核过的代码、测试及公开文档，不包含开发工作目录、内部任务记录、QQ数据、分析缓存、日志、私钥或认证文件。

## 下载与升级说明

从 1.2.0 / 1.2.1 升级时，在「设置 → 关于 → 当前版本」检查更新，按提示下载、安装并重启。升级保留账号数据、分析结果、配置和模型。

源码命令 `npm run setup:models` 支持断点续传。桌面设置中的“下载模型”使用另一套下载入口，中断后需要重新下载；本版未新增桌面断点续传能力。

人物画像继续沿用现有流程。本版消息标签和批处理改进不代表情感、意图或人格推测已达到统一的准确率指标，实际结果仍需结合聊天语境判断。
